<p id="mwAw">A <b id="mwBA">document type declaration</b>, or <b id="mwBQ">DOCTYPE</b>, is an instruction that associates a particular <a rel="mw:WikiLink" href="https://en.wikipedia.org/wiki/XML" title="XML" id="mwBg">XML</a> or <a rel="mw:WikiLink" href="https://en.wikipedia.org/wiki/SGML" title="SGML" class="mw-redirect" id="mwBw">SGML</a> document (for example, a <a rel="mw:WikiLink" href="https://en.wikipedia.org/wiki/Web_page" title="Web page" id="mwCA">web page</a>) with a <a rel="mw:WikiLink" href="https://en.wikipedia.org/wiki/Document_type_definition" title="Document type definition" id="mwCQ">document type definition</a> (DTD) (for example, the formal definition of a particular version of <a rel="mw:WikiLink" href="https://en.wikipedia.org/wiki/HTML" title="HTML" id="mwCg">HTML 2.0 - 4.0</a>).<sup about="#mwt2" class="mw-ref reference" id="cite_ref-1" rel="dc:references" typeof="mw:Extension/ref" data-mw='{"name":"ref","attrs":{},"body":{"id":"mw-reference-text-cite_note-1"}}'><a href="#cite_note-1" id="mwCw"><span class="mw-reflink-text" id="mwDA"><span class="cite-bracket" id="mwDQ">[</span>1<span class="cite-bracket" id="mwDg">]</span></span></a></sup> In the <a rel="mw:WikiLink" href="https://en.wikipedia.org/wiki/Serialize" title="Serialize" class="mw-redirect" id="mwDw">serialized</a> form of the document, it manifests as a short string of <a rel="mw:WikiLink" href="https://en.wikipedia.org/wiki/Markup_language" title="Markup language" id="mwEA">markup</a> that conforms to a particular syntax.</p>

<p id="mwEQ">The <a rel="mw:WikiLink" href="https://en.wikipedia.org/wiki/HTML" title="HTML" id="mwEg">HTML</a> <a rel="mw:WikiLink" href="https://en.wikipedia.org/wiki/Browser_engine" title="Browser engine" id="mwEw">layout engines</a> in modern <a rel="mw:WikiLink" href="https://en.wikipedia.org/wiki/Web_browser" title="Web browser" id="mwFA">web browsers</a> perform DOCTYPE "sniffing" or "switching", wherein the DOCTYPE in a document served as <code id="mwFQ">text/html</code> determines a layout mode, such as "<a rel="mw:WikiLink" href="https://en.wikipedia.org/wiki/Quirks_mode" title="Quirks mode" id="mwFg">quirks mode</a>" or "standards mode". The <code id="mwFw">text/html</code> serialization of <a rel="mw:WikiLink" href="https://en.wikipedia.org/wiki/HTML5" title="HTML5" id="mwGA">HTML5</a>, which is not SGML-based, uses the DOCTYPE only for mode selection.  Since web browsers are implemented with special-purpose HTML parsers, rather than general-purpose DTD-based parsers, they do not use DTDs and never access them even if a URL is provided.  The DOCTYPE is retained in HTML5 as a "mostly useless, but required" header only to trigger "standards mode" in common browsers.<sup about="#mwt5" class="mw-ref reference" id="cite_ref-2" rel="dc:references" typeof="mw:Extension/ref" data-mw='{"name":"ref","attrs":{},"body":{"id":"mw-reference-text-cite_note-2"}}'><a href="#cite_note-2" id="mwGQ"><span class="mw-reflink-text" id="mwGg"><span class="cite-bracket" id="mwGw">[</span>2<span class="cite-bracket" id="mwHA">]</span></span></a></sup></p>

<p id="mwkA">In XHTML documents, the doctype declaration must always explicitly specify a system identifier. In SGML-based documents like HTML, on the other hand, the appropriate system identifier may automatically be inferred from the given public identifier. This association might e.g. be performed by means of a catalog file resolving the FPI to a system identifier.<sup about="#mwt55" class="mw-ref reference" id="cite_ref-6" rel="dc:references" typeof="mw:Extension/ref" data-mw='{"name":"ref","attrs":{},"body":{"id":"mw-reference-text-cite_note-6"}}'><a href="#cite_note-6" id="mwkQ"><span class="mw-reflink-text" id="mwkg"><span class="cite-bracket" id="mwkw">[</span>6<span class="cite-bracket" id="mwlA">]</span></span></a></sup> The <code class="mw-highlight mw-highlight-lang-text mw-content-ltr" style="" dir="ltr" typeof="mw:Extension/syntaxhighlight mw:Transclusion" about="#mwt50" id="mwlQ" data-mw='{"name":"syntaxhighlight","attrs":{"lang":"text","class":"","style":"","inline":"1"},"body":{"extsrc":"SYSTEM"},"parts":[{"template":{"target":{"wt":"code","href":"./Template:Code"},"params":{"1":{"wt":"SYSTEM"}},"i":0}}]}'>SYSTEM</code> keyword can (except in XML) also be used without a system identifier following, indicating that a DTD exists but should be inferred from the document type name.<sup about="#mwt56" class="mw-ref reference" id="cite_ref-goldfarb_3-11" rel="dc:references" typeof="mw:Extension/ref" data-mw='{"name":"ref","attrs":{"name":"goldfarb"}}'><a href="#cite_note-goldfarb-3" id="mwlg"><span class="mw-reflink-text" id="mwlw"><span class="cite-bracket" id="mwmA">[</span>3<span class="cite-bracket" id="mwmQ">]</span></span></a></sup><sup class="reference nowrap" about="#mwt52" typeof="mw:Transclusion" id="mwmg" data-mw='{"parts":[{"template":{"target":{"wt":"rp","href":"./Template:Rp"},"params":{"1":{"wt":"378"}},"i":0}}]}'><span title="Page / location: 378"><span typeof="mw:Entity">:</span><span typeof="mw:Entity"> </span>378<span typeof="mw:Entity"> </span></span></sup></p>

</section><section data-mw-section-id="4" id="mwmw" aria-labelledby="Internal_subset"><div class="mw-heading mw-heading3"><h3 id="Internal_subset">Internal subset</h3><span class="mw-editsection"><span class="mw-editsection-bracket">[</span><a href="/w/index.php?title=Document_type_declaration&amp;action=edit&amp;section=4" title="Edit section: Internal subset"><span>edit</span></a><span class="mw-editsection-bracket">]</span></span></div>

<p id="mwnA">The last, optional, part of a DOCTYPE declaration is surrounded by literal square <a rel="mw:WikiLink" href="https://en.wikipedia.org/wiki/Bracket" title="Bracket" id="mwnQ">brackets</a> (<code class="mw-highlight mw-highlight-lang-text mw-content-ltr" style="" dir="ltr" typeof="mw:Extension/syntaxhighlight mw:Transclusion" about="#mwt57" id="mwng" data-mw='{"name":"syntaxhighlight","attrs":{"lang":"text","class":"","style":"","inline":"1"},"body":{"extsrc":"[]"},"parts":[{"template":{"target":{"wt":"code","href":"./Template:Code"},"params":{"1":{"wt":"[]"}},"i":0}}]}'>[]</code>), and called an <i id="mwnw">internal subset</i>. It can be used to add/edit <a rel="mw:WikiLink" href="https://en.wikipedia.org/wiki/Document_type_definition#Markup_declarations" title="Document type definition" id="mwoA">entities</a> or add/edit PUBLIC keyword behaviors.<sup about="#mwt62" class="mw-ref reference" id="cite_ref-7" rel="dc:references" typeof="mw:Extension/ref" data-mw='{"name":"ref","attrs":{},"body":{"id":"mw-reference-text-cite_note-7"}}'><a href="#cite_note-7" id="mwoQ"><span class="mw-reflink-text" id="mwog"><span class="cite-bracket" id="mwow">[</span>7<span class="cite-bracket" id="mwpA">]</span></span></a></sup> It is possible, but uncommon, to include the entire DTD in-line in the document, within the internal subset, rather than referencing it from an external file.<sup about="#mwt63" class="mw-ref reference" id="cite_ref-goldfarb_3-12" rel="dc:references" typeof="mw:Extension/ref" data-mw='{"name":"ref","attrs":{"name":"goldfarb"}}'><a href="#cite_note-goldfarb-3" id="mwpQ"><span class="mw-reflink-text" id="mwpg"><span class="cite-bracket" id="mwpw">[</span>3<span class="cite-bracket" id="mwqA">]</span></span></a></sup><sup class="reference nowrap" about="#mwt59" typeof="mw:Transclusion" id="mwqQ" data-mw='{"parts":[{"template":{"target":{"wt":"rp","href":"./Template:Rp"},"params":{"1":{"wt":"402"}},"i":0}}]}'><span title="Page / location: 402"><span typeof="mw:Entity">:</span><span typeof="mw:Entity"> </span>402<span typeof="mw:Entity"> </span></span></sup> Conversely, the internal subset is sometimes forbidden within simple SGML profiles, notably those for basic HTML parsers that don't implement a full SGML parser.</p>

<p id="mwqg">If both an internal DTD subset and an external identifier are included in a DOCTYPE declaration, the internal subset is processed first, and the external DTD subset is treated as if it were transcluded at the end of the internal subset. Since earlier definitions take precedence over later definitions in a DTD, this allows the internal subset to override definitions in the external subset.<sup about="#mwt65" class="mw-ref reference" id="cite_ref-goldfarb_3-13" rel="dc:references" typeof="mw:Extension/ref" data-mw='{"name":"ref","attrs":{"name":"goldfarb"}}'><a href="#cite_note-goldfarb-3" id="mwqw"><span class="mw-reflink-text" id="mwrA"><span class="cite-bracket" id="mwrQ">[</span>3<span class="cite-bracket" id="mwrg">]</span></span></a></sup><sup class="reference nowrap" about="#mwt64" typeof="mw:Transclusion" id="mwrw" data-mw='{"parts":[{"template":{"target":{"wt":"rp","href":"./Template:Rp"},"params":{"1":{"wt":"402–403"}},"i":0}}]}'><span title="Page / location: 402–403"><span typeof="mw:Entity">:</span><span typeof="mw:Entity"> </span>402–403<span typeof="mw:Entity"> </span></span></sup></p>

</section><section data-mw-section-id="11" id="mwAU8" aria-labelledby="HTML5_DTD-less_DOCTYPE"><div class="mw-heading mw-heading3"><h3 id="HTML5_DTD-less_DOCTYPE">HTML5 DTD-less DOCTYPE</h3><span class="mw-editsection"><span class="mw-editsection-bracket">[</span><a href="/w/index.php?title=Document_type_declaration&amp;action=edit&amp;section=11" title="Edit section: HTML5 DTD-less DOCTYPE"><span>edit</span></a><span class="mw-editsection-bracket">]</span></span></div>
<p id="mwAVA"><a rel="mw:WikiLink" href="https://en.wikipedia.org/wiki/HTML5" title="HTML5" id="mwAVE">HTML5</a> uses a <code id="mwAVI">DOCTYPE</code> declaration which is very short, due to its lack of references to a DTD in the form of a URL or FPI. All it contains is the tag name of the root element of the document, <code id="mwAVM">HTML</code>.<sup about="#mwt85" class="mw-ref reference" id="cite_ref-10" rel="dc:references" typeof="mw:Extension/ref" data-mw='{"name":"ref","attrs":{},"body":{"id":"mw-reference-text-cite_note-10"}}'><a href="#cite_note-10" id="mwAVQ"><span class="mw-reflink-text" id="mwAVU"><span class="cite-bracket" id="mwAVY">[</span>10<span class="cite-bracket" id="mwAVc">]</span></span></a></sup>  In the words of the specification draft itself:</p>

<blockquote cite="http://dev.w3.org/html5/spec/syntax.html#the-doctype" id="mwAVg"><p about="#mwt86" typeof="mw:Transclusion" id="mwAVk" data-mw='{"parts":[{"template":{"target":{"wt":"code","href":"./Template:Code"},"params":{"lang":{"wt":"html"},"1":{"wt":"&lt;!DOCTYPE html>"}},"i":0}},", case-insensitively."]}'><code class="mw-highlight mw-highlight-lang-html mw-content-ltr" style="" dir="ltr" typeof="mw:Extension/syntaxhighlight" about="#mwt87" id="mwAVo" data-mw='{"name":"syntaxhighlight","attrs":{"lang":"html","class":"","style":"","inline":"1"},"body":{"extsrc":"&lt;!DOCTYPE html>"}}'><span class="cp" id="mwAVs">&lt;!DOCTYPE html></span></code>, case-insensitively.</p></blockquote>

<p id="mwAVw">With the exception of the lack of a URI or the FPI string (the FPI string is treated case sensitively by validators), this format (a case-insensitive match of the string <code id="mwAV0">!DOCTYPE HTML</code>) is the same as found in the syntax of the SGML based HTML 4.01 <code id="mwAV4">DOCTYPE</code>. Both in HTML4 and in HTML5, the formal syntax is defined in upper case letters, even if both lower case and mixes of lower case upper case are also treated as valid.</p>

<p id="mwAV8">In <a rel="mw:WikiLink" href="https://en.wikipedia.org/wiki/XHTML5" title="XHTML5" class="mw-redirect" id="mwAWA">XHTML5</a> the <code id="mwAWE">DOCTYPE</code> must be a case-sensitive match of the string "<code class="mw-highlight mw-highlight-lang-html mw-content-ltr" style="" dir="ltr" typeof="mw:Extension/syntaxhighlight mw:Transclusion" about="#mwt88" id="mwAWI" data-mw='{"name":"syntaxhighlight","attrs":{"lang":"html","class":"","style":"","inline":"1"},"body":{"extsrc":"&lt;!DOCTYPE html>"},"parts":[{"template":{"target":{"wt":"code","href":"./Template:Code"},"params":{"lang":{"wt":"html"},"1":{"wt":"&lt;!DOCTYPE html>"}},"i":0}}]}'><span class="cp" id="mwAWM">&lt;!DOCTYPE html></span></code>". This is because in XHTML syntax all <a rel="mw:WikiLink" href="https://en.wikipedia.org/wiki/HTML_element" title="HTML element" id="mwAWQ">HTML element</a> names are required to be in lower case, including the root element referenced inside the HTML5 <code id="mwAWU">DOCTYPE</code>. </p>

<p id="mwAWY">The <code id="mwAWc">DOCTYPE</code> is optional in XHTML5 and may simply be omitted.<sup about="#mwt92" class="mw-ref reference" id="cite_ref-11" rel="dc:references" typeof="mw:Extension/ref" data-mw='{"name":"ref","attrs":{},"body":{"id":"mw-reference-text-cite_note-11"}}'><a href="#cite_note-11" id="mwAWg"><span class="mw-reflink-text" id="mwAWk"><span class="cite-bracket" id="mwAWo">[</span>11<span class="cite-bracket" id="mwAWs">]</span></span></a></sup> However, if the <a rel="mw:WikiLink" href="https://en.wikipedia.org/wiki/Markup_language" title="Markup language" id="mwAWw">markup</a> is to be <a rel="mw:WikiLink" href="https://en.wikipedia.org/wiki/Polyglot_markup" title="Polyglot markup" class="mw-redirect" id="mwAW0">processed as both XML and HTML</a>, a DOCTYPE should be used.<sup about="#mwt95" class="mw-ref reference" id="cite_ref-12" rel="dc:references" typeof="mw:Extension/ref" data-mw='{"name":"ref","attrs":{},"body":{"id":"mw-reference-text-cite_note-12"}}'><a href="#cite_note-12" id="mwAW4"><span class="mw-reflink-text" id="mwAW8"><span class="cite-bracket" id="mwAXA">[</span>12<span class="cite-bracket" id="mwAXE">]</span></span></a></sup></p>
