<!-- wp:paragraph -->
<p>เรียนรู้วิธีการดําเนินการ GitHub ที่ช่วยให้คุณสามารถทําให้วงจรการพัฒนาซอฟต์แวร์ของคุณเป็นอัตโนมัติ นี่คือส่วนที่ 1 ของชุดข้อมูลสองส่วน</p>

<!-- /wp:list-item -->

<!-- wp:list-item -->
<li>ใช้ การดําเนินการ GitHub เพื่อสร้างแอปพลิเคชันของคุณโดยอัตโนมัติ</li>
<!-- /wp:list-item -->

<!-- wp:list-item -->

<!-- wp:list-item -->
<li>เผยแพร่ไลบรารีโค้ดหรือรูปภาพ Docker ของคุณโดยอัตโนมัติและปลอดภัยด้วยแพคเกจ GitHub</li>
